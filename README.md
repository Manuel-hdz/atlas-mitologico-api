# 🌍 Atlas Mythologica

> Una plataforma Open Source para consultar, relacionar y explorar personajes, criaturas, dioses, héroes, lugares, objetos y eventos de las mitologías del mundo.

---

## 📖 Descripción

Atlas Mythologica is an open-source platform and public API dedicated to documenting, organizing and exploring mythologies from around the world.

Atlas Mitológico es una plataforma desarrollada en Laravel cuyo objetivo es convertirse en la base de datos mitológica más completa y estructurada disponible públicamente.

El proyecto proporciona:

- API REST pública
- Interfaz web
- Árboles genealógicos
- Grafos de relaciones
- Versiones alternativas de los mitos
- Fuentes clásicas
- Sincretismos entre culturas
- Exportación de datos
- Base de datos abierta para investigación y desarrollo

Actualmente el proyecto inicia con:

| Mitología | Entidades |
|-----------|----------:|
| 🇬🇷 Griega | 423 |
| 🇳🇴 Nórdica | 305 |
| 🇪🇬 Egipcia | 226 |

**Total inicial: 954 entidades**

# 🎯 Objetivos

Este proyecto busca crear una referencia pública para desarrolladores, investigadores, estudiantes y aficionados a la mitología.

No pretende definir una única versión "correcta" de cada mito, sino documentar las diferentes tradiciones existentes.

# Filosofía

Atlas Mitológico no intenta decidir cuál versión de un mito es la correcta.

Cada tradición será documentada y referenciada de forma independiente.

El proyecto diferencia claramente entre:

- genealogía
- sincretismo
- equivalencia cultural
- interpretación moderna
- adaptación literaria

Esto permite representar correctamente las múltiples variantes existentes sin perder información histórica.

# Principios

- No eliminar información histórica.

- Toda variante debe poder coexistir.

- Toda relación debe tener una fuente.

- Las equivalencias culturales nunca sustituyen al personaje original.

- Las entidades deben ser reutilizables entre distintas mitologías cuando exista sincretismo.

- Los datos deben ser estructurados y consultables mediante API.
