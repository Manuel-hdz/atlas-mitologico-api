# Roadmap

## Visión

Atlas Mitológico busca convertirse en la base de datos abierta más completa sobre mitología del mundo.

El proyecto pretende reunir, organizar y documentar entidades, relaciones, tradiciones y fuentes de múltiples culturas en un formato abierto, estructurado y reutilizable mediante una API pública.

La prioridad es construir una base sólida antes de añadir funcionalidades avanzadas.

# Objetivo a largo plazo

Convertir Atlas Mitológico en un proyecto de referencia internacional para la documentación de mitologías, ofreciendo una plataforma abierta, verificable y extensible para investigadores, estudiantes, desarrolladores y cualquier persona interesada en el estudio comparado de las tradiciones mitológicas.
